00 / Decision brief

IlùBench Elicitation Flows

How a benchmark run gets from a model API into Uche's leaderboard today, how it would flow with the Go binary as the only elicitation code, and how it would flow after the port if nothing else changes. One figure per option, same grid, so the difference is where the boxes moved.

01 / Today

Two elicitation implementations, joined by hand

Inside Uche you call the run endpoint and services/benchmark.py makes the two calls per probe and inserts response text into benchmark_runs. Outside, a researcher runs runner.py, which writes rows and a raw archive; those rows reach Uche only through a pull request to the dataset repo and a manual import.

elicitation code manual step

02 / Proposal

One binary elicits, Uche scores and publishes

You and any outside researcher run the same Go binary. Every run, internal or external, produces the same runs.jsonl rows and a raw archive. Uche stops executing probes itself and takes rows in through the importer that already exists, which needs two changes: read the raw archive to fill the arm text, and treat pending_* values as "no score" rather than a human score. Scoring, provenance, the time series and the leaderboard are untouched.

elicitation code change to make retired manual step

03 / Port without adoption

Same shape as today, with a faster public runner

The Go binary replaces runner.py for you and for outsiders, and Uche keeps executing probes with its own Python. Nothing about the internal path changes. The cost is the gold bracket: two implementations of the same protocol that only stay identical if someone checks by hand every time either one moves.

The decision

Pick before the v0.2 probe set is run, so the first v0.2 matrix is produced once, by one implementation, with a raw archive behind every row. If you choose the proposal, the two importer changes are one small Uche pull request; I can scope it after Milestone 3, when the Go binary passes the full parity suite. If you choose to keep both, the one thing worth doing anyway is the importer's arm-text fix, because it affects rows Uche already holds.
